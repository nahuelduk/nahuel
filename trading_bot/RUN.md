# Ejecutar Trading Bot

## Windows PowerShell

```powershell
cd C:\Users\pc01\nahuel\trading_bot
python -m pip install -r requirements.txt
python server.py
```

Se abre automáticamente: **http://localhost:5000**

---

## Mac/Linux

```bash
cd ~/nahuel/trading_bot
python -m pip install -r requirements.txt
python server.py
```

Se abre: http://localhost:5000

---

## Uso

1. Click en **▶ START BOT**
2. Mira los logs, trades y signals en tiempo real
3. Click en **⏹ STOP** para detener

¡Listo! Sin .exe, sin compilar, todo en el navegador.
